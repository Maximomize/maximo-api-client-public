    Class LoggerManagerService

    Logger Manager: manage Maximo log4j loggers, appenders and the calling user's thread logging over REST, without an automation script.

    Channels (all verified live on Manage 9.2 and on a 7.6.1.x on-prem server):

    • service/logging web-service methods: getLoggerList, getAppenderList, setLogLevel, activateLogger.
    • GET /refresh/MAXLOGGERCACHE applies saved changes to the running log4j configuration (the Logging app's Apply Settings).
    • Three flat object structures that setup creates on request, each authorised against the LOGGING app (or every call fails with BMXAA9301E):
      • MXSCRIPT.LOG.LOGGER: MAXLOGGER, with an Inbound Setting Restriction override on PARENTLOGGERID so a new logger gets a real parent in the Logging app tree.
      • MXSCRIPT.LOG.APPEND: MAXLOGAPPENDER.
      • MXSCRIPT.LOG.THREAD: MAXTHREADLOGGER, used to switch thread logging back off.
    • /log/* thread logging for the calling user (POST only; a GET of any /log command silently does nothing).

    Deliberately not done:

    • Writing through a self-referencing logger object structure: a nested PATCH there overwrites the parent row.
    • Deleting internal loggers or appenders, or loggers that still have children.
    • Enabling thread logging for other users and then forgetting about it: use LoggingService.enableThreadLogsFor directly for that.

    Every write that changes configuration ends with apply, so the change is live when the call returns.

    enableMyThreadLogging

    • enableMyThreadLogging(
          input: EnableThreadLoggingInput,
      ): Promise<ThreadLogConfig[]>

      Enables thread logging for the calling user in one context. Only requests made in a logged-in session are captured, never API-key calls. Contexts other than OSLC are refused until MXSCRIPT.LOG.THREAD exists, so whatever is switched on can always be switched off again.

      Parameters

      • input: EnableThreadLoggingInput

      Returns Promise<ThreadLogConfig[]>

    disableMyThreadLogging

    • disableMyThreadLogging(): Promise<ThreadLogConfig[]>

      Switches off all of the calling user's thread logging. disablealllogs only covers the OSLC context, so other contexts are cleared by re-posting them with an empty logger list, and any row left over is deleted through MXSCRIPT.LOG.THREAD (a merely disabled row blocks enabling that context again later).

      Returns Promise<ThreadLogConfig[]>
